# 管理你的图标资产

Icon Set 用来把图标整理成稳定、可分享、可协作维护的集合。它适合放置产品图标、品牌素材、第三方服务 logo，或者任何需要被前端、设计和运营反复引用的图片资产。

## 你可以先浏览

未登录时也可以查看公开集合，搜索图标，打开预览，并复制图片地址或集合分享链接。每个集合都有独立的 `manifest.json`，方便项目脚本、站点页面或设计工具按清单读取。

## 登录后可以维护

- 创建集合，补充名称、描述和图标文件。
- 上传、重命名、预览、删除图标，并同步更新 manifest。
- 复制 GitHub Raw 图片地址，直接在项目里引用。
- 创建协作链接，让未登录协作者通过 token 进入共享编辑流程。
- 设置协作链接的 password、有效期，并在需要时失效或删除。

## GitHub 是资产仓库

Icon Set 不把图标锁在应用内部。图标文件、集合清单和 manifest 都会写入你配置的 GitHub 仓库，保留 GitHub 的版本记录和权限边界。

第一次登录控制台前，建议先准备一个单独的图标资产仓库。配置方式可以看 [GitHub 仓库配置指引](/docs/github-repo-config)。

## 适合团队使用

- 前端需要稳定的 raw URL 和 manifest 文件。
- 设计、开发、运营希望共享同一份图标清单。
- 多个人维护同一套图标，但不想把 GitHub 写入权限直接交给所有协作者。
- 希望图标资产有清晰的来源、版本和可审计记录。
